# n8n Workflows — reference only, not in use

Job ingestion no longer runs on n8n. It runs in-process in the backend:
`backend/src/ingestion/` (connectors, runner, scheduler, CLI), scheduled with
node-cron behind `INGESTION_ENABLED`.

```bash
npm run ingest -- all        # every connector whose credentials are present
npm run ingest -- remotive   # one source
npm run ingest -- expire     # stale-job sweep (replaces 10-cleanup.json)
```

The files still here are kept **only** as a record of each source's fetch URL,
query parameters, and API-key variable names, for whoever writes the remaining
connectors. Do not import them into n8n and do not copy their structure.

## Why these never worked

Every file here was generated by `scripts/generate_n8n_workflows.py` and none
was validated against a running n8n. Before reusing any of the details in them,
know that they contain at least these defects:

- **The envelope was never built.** The Set nodes store `jsonOutput` starting
  with `{`, not `=`, so n8n treats it as literal JSON and never evaluates the
  expressions. `raw` arrives as the string `"={{$json.results || []}}"`, which
  the normalizer rejects. Zero jobs, every source.
- **Nodes are `typeVersion: 1`.** That version has no `jsonOutput` mode, and no
  `sendHeaders`/`headerParameters`/`jsonBody` — so `X-Internal-Service-Key` was
  never sent and the internal API would answer 401.
- **01–06 query columns that do not exist.** `SELECT external_ref FROM companies
  WHERE source=… AND is_active=true` — `companies` has none of `source`,
  `external_ref`, `base_url`, or `is_active`. That data belongs in
  `source_configs`, which is still empty.
- **18 and 22 post to the wrong path**, `/api/internal/jobs`, while the router is
  mounted at `/api/v1/internal`.

Field names in these feeds also do not match what the normalizer looks for —
RemoteOK calls the title `position`, Remotive calls the company `company_name`,
and We Work Remotely fuses both into `"Company: Title"`. Mapping each source onto
the canonical keys is what `backend/src/ingestion/connectors/` exists to do.

Note that We Work Remotely has no JSON API at all: the `/api/v1/posts` endpoint
in the old `09` workflow returns 404. The connector uses the RSS feed instead.
